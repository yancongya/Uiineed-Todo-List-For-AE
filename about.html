Interactive Personal Contact Card

Overview

This project is an interactive personal contact card designed to showcase contact information and social links in a visually engaging way. It features smooth animations and interactive elements that respond to user actions like hover and click. This about.html page serves as both a demonstration of the card and its documentation.

Features

  • Interactive Hover Effects:
    • Card expands and changes border radius on hover.
    • Profile picture zooms and becomes circular with a border.
    • Informational text content (email, description) and social icons smoothly appear.
    • User's name ("itycon") appears in the top-right corner of the card (on the white area) with an entrance and shimmer animation.
  • Clickable Icons & Text Interaction:
    • Social/contact icons (WeChat, Mail, Link, Book ID) are clickable.
    • Hovering over an icon highlights relevant segments of the email address and displays a descriptive label (e.g., "微信号码", "邮箱地址").
    • Dynamic underline animations appear under the highlighted text segments.
    • Clicking an icon copies the corresponding information (e.g., WeChat ID, full email, website domain, account ID) to the clipboard with a "已复制" (Copied) confirmation message.
  • QR Code Display:
    • Clicking the WeChat icon reveals a WeChat QR code image (public/wechat_qrcode.jpg) with a fade-in animation.
    • The QR code image can be hidden by clicking it again or when the mouse leaves the WeChat icon.
  • Customizable Content:
    • Easily updateable profile picture (animated WebP: public/coming.webp), name, email address segments, descriptive text, and icon links/actions.

Technologies Used

  • HTML5: For the structure of the card and the page.
  • CSS3: For all styling, animations (transitions, keyframes), layout (Flexbox), and responsive considerations for the card.
    • CSS Variables (:root) are used for theming and color management (e.g., --primary-color, --text-primary).
  • Vanilla JavaScript (ES6+): For all interactivity, including:
    • Event handling (hover, click, mouseleave).
    • DOM manipulation (adding/removing classes, updating styles for underlines).
    • Clipboard API (navigator.clipboard.writeText).
    • Dynamic calculation of underline positions based on text segment dimensions.
  • SVG Icons: For scalable and customizable icons (e.g., public/WeChat.svg, mail.svg, link.svg, book.svg).
  • Animated WebP: For the profile picture animation (public/coming.webp).
  • JPG Image: For the WeChat QR code (public/wechat_qrcode.jpg).
  • Fonts: Uses a common system font stack for broad compatibility: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Helvetica Neue', sans-serif.

Inspiration & References

  • The initial card component structure was inspired by a design found on uiverse.io.
  • The project has since been significantly customized with new features, animations, and a unique color scheme.

Local Setup & Deployment

To run this project locally:

  1. File Structure:
    Ensure you have the following file structure: 
    .
├── about.html  (or index.html - the main file with the card and this documentation)
├── README.md
└── public/
    ├── coming.webp         (Profile animation)
    ├── WeChat.svg          (Icon)
    ├── mail.svg            (Icon)
    ├── link.svg            (Icon)
    ├── book.svg            (Icon)
    └── wechat_qrcode.jpg   (QR Code image)
  2. Open in Browser:
    • Simply open the about.html (or your main HTML file) in any modern web browser (e.g., Chrome, Firefox, Edge, Safari).
    • No special build steps or local server is strictly required for basic viewing.
